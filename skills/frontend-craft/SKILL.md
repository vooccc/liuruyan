# 工作模式纪律 · 前端工艺档位

做 UI 时不只是"能跑"——还得"对"。下面是判断"对不对"的几条线。

## 1. 克制优于装饰

- **第一直觉是删而不是加**：能用留白说清楚的，不用 border / shadow / 渐变
- **同一信息只表达一次**：颜色已经表达了状态就不要再用图标重复，避免 UI 噪音
- **每个视觉元素必须有理由**：装饰性元素（光晕/动画/阴影）回答得出"它在传达什么"才能留
- 用户说"违和"时，先想能不能**删一层**而不是再加一层 mask 盖住违和

## 2. 状态完整性

任何 UI 都必须显式设计这五种状态，缺一不可：

| 状态 | 设计要点 |
|---|---|
| **空（empty）** | 不只是"没东西"，要有引导（图标 + 一句说明 + 行动按钮） |
| **加载（loading）** | 骨架屏 / spinner / 渐进显示，不要白屏跳变 |
| **成功（success）** | 反馈适度，不喧宾夺主（pop-in 比满屏 toast 好） |
| **失败（error）** | 明确说明"哪里出错"+"我能做什么"，不只是 ❌ |
| **极端（edge）** | 超长文本、超多条目、网络断开——都不能让 UI 崩 |

## 3. 动效服务于信息层级

- **动效不是装饰，是引导注意力**：从 A 到 B 的过渡告诉用户"这两个东西其实是一回事"
- 时长准则：
  - 反馈类（hover/click）120-200ms
  - 状态切换 200-320ms
  - 入场/离场 280-420ms
  - 超过 500ms 用户会觉得卡
- 缓动函数：`cubic-bezier(.2,.8,.2,1)` 这种"先快后慢"是默认选择，匀速 `linear` 只用于无限循环
- 必备 `prefers-reduced-motion: reduce` 兜底，关闭装饰性动画

## 4. 颜色与对比

- 文字对比度 ≥ 4.5:1（正文）/ 3:1（大字号）—— WCAG AA 是底线
- **语义色不要超过 5 种**：成功/失败/警告/信息/中性。多了用户记不住
- **降饱和优于鲜艳**：muted 色比 saturated 色耐看，做品牌时再考虑突出色
- 不要靠颜色单独传达信息（色盲用户）：色 + 形 + 文字三选二最少

## 5. 可访问性不是后期补丁

- 所有交互元素必须键盘可达（Tab 顺序合理）
- 焦点态必须可见，**不要用 `outline: none` 还不补 `:focus-visible`**
- ARIA 标签按需加，不滥加（误导比没标签还糟）
- 颜色之外的状态指示（icon、文字、形状）

## 6. 性能就是体验

- 首屏避免 CLS（布局抖动）：图片、字体、广告位都要预留尺寸
- 长列表用虚拟滚动（>200 条）
- 60fps 是底线，掉帧的动画不如不做
- 不要为了"酷"加 backdrop-filter 等性能杀手——除非真的必要

---

> **判断准则**：每写一段 CSS 都问自己——"如果删掉这行，用户会失去什么信息？"
> 答不上来就删。
